# GiftyBot

![GiftyBot Logo](https://cdn.discordapp.com/app-icons/1128566184904769570/8c0059640fdb267811af07590591f585.png)

---

## English

GiftyBot is a Discord bot designed to simplify the generation and redemption of role codes within Discord servers. With GiftyBot, you can create custom role redemption codes and allow server members to unlock special roles quickly and securely.

---

## Key Features

### Role Code Generation
GiftyBot allows you to generate custom role redemption codes with configurable options such as expiration time and usage limits.

### Role Redemption System
Server members can redeem role codes using a simple command and instantly receive the assigned roles.

### Advanced Customization
Configure GiftyBot behavior based on your requirements, such as restricting who can generate codes or who is allowed to redeem them.

---

## Commands

- `/generarcodigo` — Creates a new role redemption code  
- `/canjear` — Allows members to redeem a role code  
- `/configurar` — Customizes GiftyBot settings for your server  
- `/ayuda` — Displays information about available commands  

---

## Installation and Usage

1. Invite GiftyBot to your Discord server using the following link:  
   **Invite GiftyBot** (invitation_link)

2. Configure GiftyBot using the `/configurar` command and follow the setup instructions.

3. Use `/generarcodigo` to generate role codes and `/canjear` to allow members to redeem them.

---

## Example

```bash
/generarcodigo
```

## Características principales

### Generación de Códigos de Canje
GiftyBot te permite crear códigos de canje de roles personalizados con opciones configurables, como duración y límite de usos.

Los miembros de tu servidor pueden canjear los códigos de canje de roles con un simple comando, obteniendo así los roles especiales asignados.

### Personalización Avanzada
Configura el comportamiento de GiftyBot de acuerdo a tus necesidades, como limitar quién puede generar códigos o quién puede canjearlos.
